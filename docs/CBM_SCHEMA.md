# CBM (codebase-memory-mcp) Schema Inventory

This document outlines the SQLite schema generated by `codebase-memory-mcp` when run with `cli index_repository --mode full`. This schema forms the input contract for the StackMind Tree-Sitter Adapter (`CBMCompiler`).

## Table: `nodes`
Represents AST symbols, classes, functions, and interfaces.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `INTEGER` | Primary key, used internally for edges. |
| `project` | `TEXT` | Project name or path hash. |
| `label` | `TEXT` | Node kind (e.g., `Class`, `Function`, `Method`). |
| `name` | `TEXT` | Short name (e.g., `init`). |
| `qualified_name` | `TEXT` | Full dot-separated name (e.g., `app.server.init`). |
| `file_path` | `TEXT` | Relative path to the file containing the node. |
| `start_line` | `INTEGER` | 1-indexed starting line. |
| `end_line` | `INTEGER` | 1-indexed ending line. |
| `properties` | `TEXT` | JSON-encoded dictionary of extra properties (e.g., `{"hash": "..."}`). |

## Table: `edges`
Represents structural relationships between nodes.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `INTEGER` | Primary key. |
| `project` | `TEXT` | Project name or path hash. |
| `source_id` | `INTEGER` | Foreign key to `nodes.id` (caller/owner). |
| `target_id` | `INTEGER` | Foreign key to `nodes.id` (callee/target). |
| `type` | `TEXT` | Relationship type (e.g., `CALLS`, `INHERITS`). |
| `properties` | `TEXT` | JSON-encoded dictionary of extra edge properties. |

## Table: `projects`
Contains project-level metadata.

| Column | Type | Description |
| :--- | :--- | :--- |
| `name` | `TEXT` | Project identifier. |
| `indexed_at` | `TEXT` | ISO-8601 timestamp of when indexing completed. |
| `path` | `TEXT` | Absolute path to the repository root. |
