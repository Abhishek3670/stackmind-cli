The Knowledge Compiler Pipeline

Five stages turn authoritative state into derived knowledge. Stages 1–4 are deterministic and LLM-free — same inputs, byte-identical outputs. Stage 5 annotates asynchronously across the boundary: ai blocks only, never structure.
