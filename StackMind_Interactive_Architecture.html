    CEO->>Claude: Define Goal / Feature Request
    Claude->>Claude: Draft Work Order & CONTRACT-01 Scope
    Claude->>Harness: Register WO & Contract in .sync/
    
    loop Worker Harness Loop
        Harness->>Worker: Poll Inbox & Trigger Execution Task
        Worker->>Gate: Query Knowledge API (Contract-Filtered)
        Gate-->>Worker: Return Bounded Context Bundle
        Worker->>Worker: Generate Implementation / Code Staging
        Worker->>Gate: Validate Staged Diff & D025 Safeguards
        Gate-->>Worker: Scope & Safety Verification
    end

    Worker->>Gemma: Submit Code for Review & QA Verification
    alt Rejected
        Gemma-->>Worker: Return QA Defects to Inbox
    else Approved
        Gemma->>Claude: Emit APPROVED Verdict Receipt
        Claude->>Local: Directive to Create Signed Git Commit
        Local->>Local: Execute Commit & Sign SHA
        Local-->>Claude: Return Signed SHA
        Claude-->>CEO: Close Work Order & Report Completion
    end

flowchart TD
    START["▶️ Start Harness Task Execution"] --> POLL["📬 Poll Work Orders & Inboxes"]
    POLL --> CONTRACT_CHK["📜 Validate Active CONTRACT-01 Gate"]
    
    CONTRACT_CHK -->|Contract Passed| LOCK["🔒 Acquire Advisory Write Lock"]
    CONTRACT_CHK -->|Contract Violation| REJECT_C["❌ Reject Task & Log Violation"]

    LOCK --> CTX["🧠 Assemble Context via Knowledge API"]
    CTX --> LLM_CALL["🤖 Call Agent LLM"]
    LLM_CALL --> SCHEMA_CHK["📋 Validate Output against Harness JSON Schema"]

    SCHEMA_CHK -->|Schema OK| D025{"🛡️ D025 Destructive Operations Check"}
    SCHEMA_CHK -->|Schema Fail| REJECT_S["❌ Reject Response & Retry"]

    D025 -->|Safe Change| DRAFT["✍️ Draft Code Modification in Worker Isolation"]
    D025 -->|Destructive Action Detected| BACKUP["💾 Enforce Mandatory Backup & CEO Escalation"]
    BACKUP --> DRAFT

    DRAFT --> PROMOTE["🚀 Promote Worker Draft to Canonical State"]
    PROMOTE --> RELEASE["🔓 Release Write Lock"]
    RELEASE --> DONE["✅ Task Complete & Receipt Written"]
